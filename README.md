# IPGeolocation

A web-based utility for retrieving and displaying **IP geolocation information** in a simple and accessible interface.

## Overview

IPGeolocation helps users inspect an IP address and view key metadata such as approximate location, network details, and related connection information.

## Features

- 🌐 Lookup IP location details
- 🧭 Display region/country/network information
- ⚡ Fast and lightweight browser-based UI
- 🧱 Built with JavaScript, HTML, and CSS

## Tech Stack

- JavaScript
- HTML
- CSS

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/hojjatnikan/IPGeolocation.git
   ```
2. Open the project directory
3. Run with your preferred static server (or open the HTML entry file if applicable)

## Use Cases

- Quick diagnostics for IP origin
- Basic network troubleshooting
- Educational/reference use
